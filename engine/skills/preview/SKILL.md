# 直接把成果弹给用户看

## 为什么有这个

做好的网页贴一段源码给用户，等于让他自己复制、存文件、找浏览器——他还得知道你写在哪个路径。
App 里本来就有网页预览和文件预览，缺的只是「你叫它打开」这一步。

**用这个技能，不要用「请复制这个地址到浏览器」这种话。**

## 怎么用

```sh
node <DSH根>/skills/preview/preview.mjs open index.html --go
```

不给 `--go` 是空跑，只打印会打开什么。改完文件重新弹一次就行，App 会刷新。

想看看哪个文件能预览：

```sh
node <DSH根>/skills/preview/preview.mjs list
```

## 能预览什么

`.html` `.htm` `.xhtml` `.svg` `.png` `.jpg` `.jpeg` `.gif` `.webp` `.pdf` `.md`

其它类型会直接报错并列出可预览的类型——别硬来，先转成 html 再弹。

## 三条要注意的

1. **给绝对路径或工作区相对路径**，别给 `~/xxx` 这种（不会展开）。
2. **单文件优先**：如果页面依赖 `style.css`、`app.js`，它们要在同一个目录里，
   相对路径才解析得到。要分发就打成单文件。
3. **这是给人看的动作**，不是收藏。用户说「先别弹」或者正在输入时，先别打扰。

## 和面板的区别

- **面板**（`schemaJson`）是嵌在对话里的一小块结构化内容：几个数字、一排按钮。
- **预览**（本技能）是整页真实网页或真实文件：有滚动条、有样式、能跑脚本。

做小仪表盘/信息卡用面板，做完整页面/成品网站用预览。
