# 远程工作台

文件来源：用户 2026-11-08：「让他连接服务器 然后去服务器里弄」

两种模式：**纯本地**（默认，零连接）和**已连接**（多出 10 个远程工具）。

---

## 用户说「连服务器」时的完整流程

**不要让用户去设置页翻。** 就在对话里问，用 `ask_user_question` 一次问一项。

### 第 1 步：问地址

> 你的服务器地址是多少？形如 `http://1.2.3.4:8092` 或 `https://你的域名:8092`（要 MCP 端口，不是网页端口）

**如果用户不知道**，告诉他去哪看：
- 服务器上跑 `cat /opt/wb/data/.access.key` 能拿口令
- 端口在部署脚本最后会打印

### 第 2 步：问口令

> 访问口令是多少？（在服务器的 `/opt/wb/data/.access.key` 里）

如果服务器没配口令，就留空。

### 第 3 步：探活（**必须先做**）

```sh
node "$DSH_TOOLS/remote-workbench/workbench.mjs" probe --url <地址> --token <口令>
```

退出码 0 = 通，1 = 不通。**不通就不要写配置**，把具体原因告诉用户：

| 工具返回 | 说明什么 | 让用户怎么办 |
|---|---|---|
| `口令不对` | 口令错 | 去服务器 `cat /opt/wb/data/.access.key` 对一下 |
| `服务器要求口令` | 没给口令但服务器要 | 问用户要口令 |
| `连不上` | 地址错 / 端口没放行 / 服务没起 | 逐条排查 |
| `不是 JSON` | 地址指到别的服务了 | 确认端口是不是 8092 |

### 第 4 步：写入

```sh
node "$DSH_TOOLS/remote-workbench/workbench.mjs" set --url <地址> --token <口令>
```

### 第 5 步：**必须如实告诉用户要重启**

> 配好了。**从后台划掉本 App 再重新打开**，Agent 才会拿到远程工具。
> 引擎只在启动时读这份配置，现在还没生效。

**不要说"已经连上了"**——那是不真实的。配置写好了 ≠ 工具可用。

## 连上之后能做什么

工具列表里会多出 `mcp__workbench__*`：

| 工具 | 一句话 |
|---|---|
| `wb_submit_task` | 提交开发需求，**异步**返回 id |
| `wb_task_status` | 查任务：阶段、门禁结果、产物路径 |
| `wb_list_tasks` / `wb_move_task` | 看板 |
| `wb_memory_search` / `wb_memory_save` | 长期记忆 |
| `wb_list_skills` | 已沉淀的技能模板 |
| `wb_stats` / `wb_health` | 状态 / 可达性 |
| `wb_evolve_advice` | 系统自评的短板 |

## 什么时候交给远程

判断标准是**执行成本和验收强度**，不是任务看起来大不大：

| 情况 | 处理 |
|---|---|
| 生成完整可运行的项目 | 远程，`wb_submit_task` |
| 需要真跑起来 + 严格验收 | 远程，它的交付链有门禁 |
| 云端可能积累过同类经验 | 先 `wb_memory_search` |
| **改一个文件、跑一条命令、回答问题** | **本地做**，别绕远程 |
| **要访问手机本地文件、相册** | **本地做**，远程碰不到 |

---

## 提交任务后必须做的

`wb_submit_task` 立刻返回 id，任务还在 `triage`。**不要**说"已经做好了"：

1. 记下 id，告诉用户「已提交，在跑」
2. 稍后用 `wb_task_status` 查
3. 把 `gate.checks` 里**真实的验收结果**转告用户
4. 到 `done` 给产物路径；到 `blocked` 说明哪一项没过

## 断开

```sh
node "$DSH_TOOLS/remote-workbench/workbench.mjs" clear
```

也要重启才生效。

---

## 常见问题

**用户说「我用不了远程工具」**
先跑 `workbench.mjs show` 看配置在不在。在的话问他重启过没有。

**用户说「太贵了」**
远程工具每轮固定消耗约 1.2 千 token（10 个工具），即使不用。建议用完就 `clear`。

**用户给的是网页地址**
比如 `http://1.2.3.4:8899`——那是工作台网页，不是 MCP。要换成 8092 端口。
