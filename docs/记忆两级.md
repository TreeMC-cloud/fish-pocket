# 记忆分两级

状态：活

> 一个判据决定写哪里。写错层级 = 有的看不到，或者污染别人。

---

## 判据只有一句

```
只有我这个场景关心          → 场景私有
别的场景也要知道 / 会影响别人 → 全员共享
```

**拿不准就往私有写。** 私有写多了只是自己啰嗦；共享写错了是污染别人。

---

## 两级分别是什么

### 私有（只有本场景能读写）

| 文件 | 放什么 | 体积红线 |
|---|---|---|
| `HANDOFF.md` | 当前进度、下一步、卡点 | ≤ 4 KB |
| `IDENTITY.md` | 我是谁、我的边界 | ≤ 4 KB（工具生成）|
| `.scene.json` | 场景配置 | — |
| 场景自己的数据目录 | 项目文件 | — |

**谁能写**：只有这个场景的会话。**别的场景看到也不能改。**

### 共享（所有场景读，按规矩写）

| 板 | 回答 | 谁能写 |
|---|---|---|
| **待办板** | 该做什么 | 任何场景加一行，⛔ 不许改别人的行 |
| **通知板** | 发生了什么 | 任何场景写，只追加 |
| **总索引** | 东西在哪 | 新建/移动时登记 |
| **体检结果** | 机器健康吗 | 只有体检工具写 |

## 最容易犯的三个错

### 错 1：把「项目细节」写进共享

```
❌ 待办板：补 src/auth.mjs 第 42 行的 token 刷新 bug
✅ 待办板：认证模块的 token 刷新有问题（详见 HANDOFF.md）
```

**为什么**：待办板是给所有场景看的，别的地方看不懂 `src/auth.mjs` 是什么。

### 错 2：把「通用规矩」写进私有

```
❌ 场景 A 的 HANDOFF.md：以后所有代码都要跑 selfcheck
✅ AGENTS.md：交付前跑 selfcheck（这是全员规矩，不是场景进度）
```

**为什么**：写进私有的话，场景 B 不知道这条规矩。

### 错 3：把「临时状态」写进共享

```
❌ 通知板：我正在改 scene.mjs（改完了）
✅ 通知板：scene.mjs 的 territory 字段已加（改完了）
```

**为什么**：共享层是历史记录，写"我正在"三天后就没意义了。

## 怎么判断

### 三个问题

```
1. 别的场景需要知道这件事吗？
   不需要 → 私有
   需要 → 继续问

2. 这件事会影响别人的工作吗？
   会 → 共享
   不会 → 私有

3. 三天后还有用吗？
   有用 → 共享
   没用 → 私有（或者根本不写）
```

### 一张对照表

| 内容 | 写哪里 |
|---|---|
| 「a.mjs 第 42 行有个 bug」 | 私有 `HANDOFF.md` |
| 「交付前必须跑 selfcheck」 | 共享 `AGENTS.md`（宪法）|
| 「我负责 engine/ 目录」 | 私有 `IDENTITY.md` |
| 「我正在做 X」 | **不写**（没人需要知道过程）|
| 「X 做完了，产物在 Y」 | 共享 通知板 |
| 「还有 3 件事没做」 | 共享 待办板 |
| 「文件 Z 在 docs/ 下」 | 共享 总索引 |
| 「体检发现 3 个问题」 | 共享 体检结果 |

## 三条硬约束

### 1. 一个能力只有一个落点

```
⛔ 不要「记忆既写在 HANDOFF.md 又写在待办板」
✅ 一个事实只有一个权威出处，别处只放指针
```

**为什么**：两处写同一个事实，早晚不一致。

### 2. 缓存不进备份，板类进台账

| 类型 | 举例 | 处理 |
|---|---|---|
| 缓存 | 检索结果、中间产物 | 可以随时删 |
| 板类 | 待办、通知、索引 | 要留痕，不能删 |

### 3. 注入失败不许阻断开场

**如果记忆读不出来，会话照常开始，只是没有历史。**

```
⛔ 不要：记忆文件损坏 → 报错退出
✅ 应该：记忆文件损坏 → 记一条警告，继续跑
```

**为什么**：记忆是辅助，不是前置条件。因为读不到记忆就不干活，等于因小失大。

## 检查

```sh
node "$DSH_TOOLS/selfaudit/selfaudit.mjs" .
```

- **R1/R2**：私有交接是否合格、是否超 4KB
- **R7**：共享层有没有积压
- 记忆分级本身**目前没有自动检查**——靠写的时候判断

**要补的话**：检查 `HANDOFF.md` 里有没有出现「所有场景」「以后都」「统一」这类词（那是通用规矩，不该在私有层）。
