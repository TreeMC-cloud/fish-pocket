## 这是什么

把 **DeepSeek Harness（DSH）引擎**移植到 iPhone，让它在你手机上跑一个**会自己干活的 Agent**，而不是一个聊天窗口。

---

## 三层结构

```
┌─ 界面层（SwiftUI，51 个视图）
│    对话 / 设置 / 文件 / 终端 / 灵动岛
├─ 引擎层（Node 24 + DSH，90+ 插件）
│    对话循环 · 工具调用 · 技能加载 · MCP 连接
└─ 工具层（16 个技能 + 16 个工具）
     记忆 · 体检 · 协作 · 交付自查
```

---

## 记忆怎么分层

七层，由 `meow-memory` 插件用 SQLite 管：

| 层 | 放什么 | 什么时候进上下文 |
|---|---|---|
| **soul** | Agent 的自我定位 | 首轮注入 |
| **user** | 你的偏好、习惯、禁忌 | 首轮注入 |
| **project** | 项目专属记忆 | 命中时检索 |
| **fact** | 客观事实 | 命中时检索 |
| **lesson** | 踩过的坑 | 命中时检索 |
| **rules** | 硬性约束 | 命中时检索 |
| **topic** | 背景知识 | 按需 |

**关键**：不是全量注入。首轮只带 soul + user，之后每轮按关键词检索 top-2。

**为什么这样**：全量注入的话，10 轮对话就要重复读 10 遍全部记忆，token 翻十倍不说，重要信息还被淹没。

## 三条不变量

这三条**任何情况下都不能违反**：

### 1. 一单一 owner

同一件事同一时刻只有一个负责人。换人要显式交接，不能两个会话同时改同一批文件。

### 2. 证据 > 声明

说"做完了"不算，必须给可复核的东西：命令输出、文件路径、URL、读回的内容。

**判据**：「活干完了但对方还不知道」= 没干完。只在自己这边说"好了" = 等于没说。

### 3. 人只批「解释 / 承诺 / 报价 / 新范围」

机械动作不要逐条找人确认。但改方向、加范围、花时间超过预期，必须问。

## 默认空跑

**所有会写文件的工具，默认只打印计划，加 `--go` 才真执行。**

```
node prefs.mjs set interaction "叫我宿主"
  → [空跑] 将写入偏好：1 条
  → （空跑）会记进交互偏好：叫我宿主
  （文件没变）

node prefs.mjs set interaction "叫我宿主" --go
  → ✓ 已记（交互偏好）：叫我宿主
  （文件写了）
```

**为什么**：Agent 会看错上下文。它以为在清理临时文件，实际可能删了源码。默认空跑让"看一眼再决定"成为默认路径。

详见 [engine/skills/_CONVENTIONS.md](../engine/skills/_CONVENTIONS.md)。

## 这个项目不做什么

| 不做 | 为什么 |
|---|---|
| 不做通用助手 | 目标是「越用越懂你」，不是回答所有问题 |
| 不追求全自动 | 关键决策要人确认（改范围、花钱、对外） |
| 不内置大模型 | 只用你填的 API Key，不偷偷走我们的服务 |
| 不强制连服务器 | 留空地址就是纯本地 |
