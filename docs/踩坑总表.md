# 踩坑总表

状态：活

> 按「症状 → 根因 → 怎么修」组织。遇到奇怪问题时先查这里。

---

## 一、环境类

### 症状：`free -m` 显示内存充足，实际已经吃紧

```
$ free -m
        total  used  free  available
Mem:     4096     0  4096          0     ← 永远这个值
```

**根因**：iSH 上 `free -m` 是**静态桩**，不反映真实内存。`/proc/meminfo` 也不可信——实测分配 500MB 后它只变一次就冻结。

**怎么修**：`load.mjs` 检测到两个源差超过总量 50% 时，标记"数据不可信"，**降级为警告不拦截**。

**教训**：拿假数据判"内存不足"会误杀正常任务，比没有检查更糟。

---

### 症状：`loadavg` 显示负载 85，但这台机器什么事都没干

**根因**：iOS 把**宿主机**的 loadavg 透传进来，不是沙箱自己的。

**判据**：`load1 > 核数 × 1` 且**沙箱内没有对应数量的 runnable 进程** → 判定为透传值，跳过。

**怎么修**：`load.mjs` 用三条启发式识别（全 0 / >核数 / 1分钟比15分钟 < 0.5），识别到就跳过 CPU 判据。

---

## 二、路径类

### 症状：技能文档里写的 `node selfcheck.mjs` 报「找不到模块」

**根因**：Agent 的工作目录是 `workspace`（可写），脚本在 `/opt/dsh/nodejs-project/skills/`（只读 app bundle）。**两者不在同一路径下。**

**怎么修**：`main.mjs` 注入 `DSH_TOOLS` 环境变量指向技能根目录，技能文档改写：

```sh
node "$DSH_TOOLS/self-review/selfcheck.mjs" --dir src
```

**教训**：不修这个，写完的所有工具都调不到，等于死文件。

---

### 症状：`/tmp/audit` 建不了目录（`No such file or directory`）

**根因**：iSH 上某些路径名可能已被占用或有坏 inode。

**怎么修**：测试一律用 `mktemp -d` 拿随机路径，不要写死 `/tmp/xxx`。

---

## 三、配置类

### 症状：配好的场景，重启 App 后没了

**根因**：`main.mjs` 每次启动都**覆盖** `$DSH_HOME/AGENTS.md`。场景身份写在同一个文件里，被冲掉了。

**怎么修**：改成只在文件不存在时复制；存在时保留 `<!-- SCENE:BEGIN -->` 之后的全部内容，只重写包内铁律那一段。

**验证**：二次启动后场景段和铁律都在，`SCENE:BEGIN` 标记数量为 1（不堆积）。

---

### 症状：填了正确的口令，测试连接却失败

**根因**：`/health` 接口**不鉴权**，所以拿它探活永远通过。真正调用时才 401。

**怎么修**：探活时多验一步——除了 `/health`，再拿 `tools/list` 打一次 `/mcp` 验证口令。

**教训**：检查用的接口如果和实际用的接口不是同一条路径，检查就不可靠。

---

### 症状：YAML 写得好好的，解析失败 `could not determine a constructor for the tag 'tag:yaml.org,2002:js'`

**根因**：这不是 bug。`!!js process.env.DSH_IOS_DOCUMENTS` 是 **DSH 自定义标签**，python yaml 不认识但 dsh 自己能解析。

**怎么判断**：用宽松 loader 验证结构，或直接看 dsh 能不能启动。

---

## 四、工具类

### 症状：工具明明"成功"了，但文件没变

**根因**（两个）：
1. 空跑模式下 `console.log('✓ 已记')` 照旧打印，但实际没写
2. `ensure()` 之类的初始化函数在空跑时也建了文件

**怎么修**：
- 所有成功文案改成条件式：`GO ? '✓ 已记' : '（空跑）会记'`
- 初始化函数开头加 `if (!GO) return;`

---

### 症状：加了 `--go` 参数，结果被当成内容写进文件

```
写进去的: "叫我宿主 --go"
```

**根因**：`process.argv.slice(2)` 包含了 `--go`。

**怎么修**：
```js
const argv = process.argv.slice(2).filter(a => a !== '--go');
```

---

### 症状：`identity.mjs` 跑一下就把 `IDENTITY.md` 覆盖了

**根因**：默认行为是写文件。身份卡写错会影响**后续所有对话**的自我认知。

**怎么修**：改成默认只预览（输出到 stdout），加 `--write` 才落盘。

**同类**：`fetch-index.mjs` 原来无参就开始几十次网络请求，也改成必须先给输出路径。

---

## 五、MCP / 远程类

### 症状：工作台连不上，但错误信息里带着内网地址

```
fetch failed: connect ECONNREFUSED 127.0.0.1:8091
```

**根因**：Node 的原始异常带着完整 URL，会直接进模型上下文并展示给用户，泄露内部分布式部署细节。

**怎么修**：捕获后换成可行动的一句话：

```
连不上工作台，检查服务器地址、端口是否放行，以及服务是否在运行
```

---

### 症状：`tools/call` 传了字符串参数，报"连不上工作台"

**根因**：`arguments` 类型没校验，字符串/数组直接穿到真实调用，最后报的是无关的网络错误。

**怎么修**：调用前校验 `typeof rawArgs === 'object' && !Array.isArray(rawArgs)`，否则返回参数错误。

---

## 六、构建类

### 症状：IPA 推送失败 `Body should be a JSON object`

**根因**：GitHub Contents API 单文件上限 **1MB**，`index.json` 有 2.6MB。

**怎么修**：改用 Git Data API（blobs → trees → commits → refs），没有大小限制。脚本见 `scripts/push-big.sh`。

---

### 症状：IPA 下载了 106MB 但 zip 校验失败

**根因**：文件真实大小**不是估算值**。之前用了 106,294,791，实际是 106,319,152——差 24,361 字节，尾部缺 EOCD。

**怎么修**：`curl -r 0-0 -D -` 从 `Content-Range: bytes 0-0/<TOTAL>` 读真实总长，**绝不估算**。

---

### 症状：分段下载拼接后 zip 损坏

**根因**：`cat p*` 按字母序拼，`p10` 排到了 `p2` 前面。

**怎么修**：
```sh
i=0
while [ $i -lt $N ]; do cat "p$i" >> out.zip; i=$((i+1)); done
```

## 七、我自己犯的错

### 以为"验证通过"其实什么都没发生

某次以为 `pdftotext` 是工具自动装的（`which` 返回空），查 `dpkg.log` 才发现**今早 06:29 就装好了**——`which` 返回空是 shell 命令缓存。

**教训**：`which` 返回空不等于没装。要么 `hash -r` 清缓存，要么直接跑一次看。

---

### 凭猜测调 API，4 个全错

调 `meow-memory` 时：
- `db.count()` → 实际要 `db.count(level)`
- `db.allActive()` 当数组 → 实际返回**按层分组的对象**
- `buildInjection(db, ws)` → 实际要 3 个参数
- `isDreamSuppressed(cfg.dream)` → 实际 cfg 直接是 dream 配置

**教训**：**读源码，不要猜**。`fn.toString().slice(0,300)` 就能看到真实签名。

---

### 并行跑 10 个 node，丢了 5 个

```
并发 10 次 dispatch → 台账只落了 4-5 条
```

**根因**：iSH 内存不足，node 进程 `uv_thread_create` 断言失败，**id 打印了但没写盘**。

**判据**：串行 10 次全成功，并发 3 次全成功，并发 10 次丢一半。

**怎么修**：批量操作要么串行，要么分批（每批 ≤3）。这不是代码缺陷，是环境限制。
